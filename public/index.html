Active users, sessions, engagement, screens and events for iOS + Android. Uses the service account from the Google Play section above. Every GA4 property it can view is discovered automatically — one per Firebase project.

Comma-separated numeric IDs from GA4 → Admin → Property details (not the G-XXXX Measurement ID).
One-time access setup
1. Enable the Google Analytics Data API and Admin API in the service account's Cloud project
2. In each Google Analytics account → Admin → Account access management, add your service account email as a Viewer (covers every property in that account)
3. Optional: Android crash/ANR rates come from Play Vitals and work automatically once Google Play is configured

Google Play data via GCS Bucket

Download stats are fetched automatically from your Play Console's GCS bucket using gsutil. Requires gcloud CLI installed and authenticated:

# Install gcloud CLI (if not installed)
brew install google-cloud-sdk

# Login with a Google account that has Play Console access
gcloud init
gcloud auth login

The authenticated Google account must have access to the Play Console with permission to view reports.
